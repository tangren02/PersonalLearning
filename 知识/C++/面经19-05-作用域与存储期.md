# 全局变量与局部变量

## 来源

Q12：[[基础面经19_上.pdf#page=12|第 12 页]]。完整映射见 [[基础面经19-原题索引]]。

## Q12：全局变量和局部变量的区别

| 比较项 | 全局变量 | 局部变量 |
| --- | --- | --- |
| 作用范围 | 整个程序 | 所在代码块 |
| 生命周期 | 程序始终 | 代码块执行期间 |
| 存储位置 | 通常在数据段 | 通常在栈中 |
| 默认初始化 | 零 | 未初始化时为“未定义值” |

## 使用建议

减少全局变量的使用，避免命名冲突和意外修改。

## 示例片段：两个变量

摘取 Q12 的声明，保留全局与函数内局部两个位置，省略输出语句及 main。globalVar 初始值为 10，函数执行时 localVar 为 20。

```cpp
int globalVar = 10;
void function() {
    int localVar = 20;
    // 输出省略
}
```
