## Q34：没有虚函数时实现多态的方法

1. **函数指针**：实现运行时多态。
2. **std::function**：存储函数对象。
3. **手动类型擦除**：通过手动类型擦除实现多态。
4. **模板**：实现编译时多态。
各方法有适用场景和局限性，应根据具体需求选择。

## Q41：虚继承解决菱形继承问题

虚继承用于解决菱形继承（钻石继承）。
多继承中的重复继承路径会使基类成员重复继承，产生冗余和潜在二义性。通过虚基类，基类成员在继承链中只存在一份。

### 示例片段

Derived1、Derived2 都虚继承 Base，Final 通过两条路径继承后仍可直接访问一份 value。

```cpp
class Base { public: int value; };
class Derived1 : virtual public Base {};
class Derived2 : virtual public Base {};
class Final : public Derived1, public Derived2 {};
Final f;
f.value = 10;
```

## Q56：静态多态与动态多态

| 比较项 | 静态多态（编译时多态） | 动态多态（运行时多态） |
| --- | --- | --- |
| 实现方式 | 函数重载、模板（泛型编程） | 虚函数、继承 |
| 解析时间 | 编译时已确定调用哪个函数版本 | 运行时决定调用哪个方法 |
| 性能 | 通常更快，调用已在编译时解析 | 可能稍慢，运行时需要查找合适函数 |

## Q57：重载与重写的区别

| 比较项 | 重载 | 重写 |
| --- | --- | --- |
| 定义层次 | 同一作用域 | 派生类与基类 |
| 参数列表 | 不同 | 相同 |
| 关键字 | 不需要特殊关键字 | 基类函数使用 virtual |
| 目的 | 同名函数提供不同实现 | 派生类提供基类函数的不同实现 |

### 示例片段

省略输出实现；Derived 的无参 display 重写基类虚函数，同类内的 display(int) 提供另一个参数列表。

```cpp
class Base {
public:
    virtual void display() const {}
};
class Derived : public Base {
public:
    void display() const override {}
    void display(int x) const {}
};
Derived derived;
derived.display();
derived.display(10);
```
