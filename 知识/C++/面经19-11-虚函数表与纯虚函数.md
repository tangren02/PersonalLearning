## Q30：虚函数的机制与好处

1. **动态绑定**：虚函数调用在运行时解析，到程序运行时才确定调用哪个函数。
2. **虚函数表（vtable）**：每个含虚函数的类有一张函数指针数组，元素对应类中的虚函数，用来查找正确实现。
3. **虚表指针（vptr）**：每个含虚函数的对象有一个指向其类虚函数表的指针，是动态绑定的关键。
好处：提高灵活性，在不修改现有代码时添加行为；通过继承和覆盖重用、扩展代码；基类定义接口、派生类实现具体功能，保持接口一致性。

### 示例片段

省略 show 的输出实现；把 Derived 对象交给 Base 引用，运行时调用 Derived::show。

```cpp
class Base {
public:
    virtual void show() {}
    virtual ~Base() {}
};
class Derived : public Base {
public:
    void show() override {}
};
void function(Base& b) { b.show(); }
Derived d;
function(d);
```

## Q31：不能声明为虚函数的函数

1. **构造函数**不能声明为虚函数：对象构造时尚未建立虚函数表。
2. **静态函数**不能声明为虚函数：没有 this 指针，与对象无关。
3. **内联函数**可以声明为虚函数，但内联特性会被编译器忽略。

## Q32：构造和析构函数能否为虚函数

构造函数不能是虚函数：对象尚未完全构造好，vptr 可能尚未设置，或尚未指向最终的类。
析构函数可以是虚函数：对象销毁时，vptr 已指向正确的虚函数表。
基类析构函数为虚函数时，通过基类指针删除派生类对象会调用派生类析构函数，确保正确释放资源，防止内存和其他资源泄漏。

## Q33：虚函数表的创建分配与初始化阶段

1. **编译阶段**：编译器分析类的声明和定义，确定含有虚函数的类，创建虚函数表，包含指向虚函数的指针。
2. **链接阶段**：链接器给虚函数表分配具体内存地址，将它们放入全局内存空间，确保各表地址唯一。
3. **运行时**：对象实例化时初始化 vptr，使其指向对应类的虚函数表；每个含虚函数的对象有自己的虚表指针。

## Q35：同类对象共享虚函数表

是。同一个类的所有对象共享同一张虚函数表。
每个对象都有自己的 vptr，指向该类的虚函数表，因此同类对象的虚函数调用经过相同的表。

### 示例片段

假设 Base 定义虚函数 show 和虚析构函数，Derived 覆盖 show 与析构；省略两个类的声明。

```cpp
Base* b = new Derived();
b->show();
delete b;
```

Base 与 Derived 各有自己的虚函数表。b 指向的 Derived 对象，其 vptr 指向 Derived 的表；调用 Derived::show，删除时先调用 Derived 析构，再调用 Base 析构。

## Q36：虚函数表存储与vptr初始化

**虚函数表**：
- 全局共享，每个类型只有一张表，在编译时构造完成；类似大小固定、全局共享的静态成员变量。
- 类似数组，存储虚函数地址；对象通过 vptr 指向它。
- 大小在编译时确定，无需运行时动态分配，不在堆区。
- Linux/Unix 通常放在可执行文件的只读数据段 .rodata；Windows 可能放在常量段。
**vptr**：
- 在类的构造函数执行时初始化，指向对应虚函数表。
- 位于对象内存布局最前面，是对象的一部分。
- 存储在对象所在区域：局部对象在栈上，动态分配对象在堆上。
通过基类指针或引用操作对象时，可由 vptr 找到实际类型的虚函数表，实现动态多态。

## Q37：虚函数表属于类还是对象

虚函数表属于类，不属于对象。
每个包含虚函数的类有一张表，存储指向该类虚函数实现的指针；对象中保存指向该表的 vptr。

## Q38：虚函数内部调用非虚函数

虚函数通过虚函数表进行动态绑定，调用实际对象的虚函数实现。
非虚函数采用静态绑定，在编译时确定调用哪个函数；虚函数内部调用的是当前对象所属类的非虚函数。

### 示例片段

Base 与 Derived 都定义 show 和 print，其中 show 是虚函数，print 不是；各 print 的输出实现省略。

```cpp
class Base {
public:
    virtual void show() { print(); }
    void print() { /* 输出 Base print */ }
};
class Derived : public Base {
public:
    void show() override { print(); }
    void print() { /* 输出 Derived print */ }
};
Derived d;
Base* b = &d;
b->show();
```

调用路径为 b->show() → Derived::show() → Derived::print()。

## Q39：纯虚函数的实现原理

纯虚函数用于定义接口，没有具体实现；含纯虚函数的类是抽象类，不能实例化。
它依赖 vtable 和 vptr：编译器为包含虚函数的类生成虚函数表，表中保存虚函数指针；对象包含指向该表的 vptr，运行时通过二者实现动态绑定。

### 示例片段

Base 用 =0 定义纯虚函数，Derived 实现 show；通过 Base 指针调用的是 Derived 的实现。

```cpp
class Base {
public:
    virtual void show() = 0;
};
class Derived : public Base {
public:
    void show() override { /* 输出派生类实现 */ }
};
Derived d;
Base* b = &d;
b->show();
```

## Q40：纯虚函数的使用场景

纯虚函数主要用于定义接口，确保派生类实现特定行为。

1. **接口定义**：定义接口类，要求派生类实现特定方法。
2. **多态实现**：通过基类指针或引用调用派生类实现。

### 示例片段

Shape 声明 draw 接口，Circle 和 Square 各自实现；省略类体与输出实现，只展示必要声明和调用。

```cpp
class Shape { public: virtual void draw() = 0; };
class Circle : public Shape { public: void draw() override {} };
class Square : public Shape { public: void draw() override {} };
void renderShape(Shape& shape) { shape.draw(); }
Circle circle;
Square square;
renderShape(circle);
renderShape(square);
```

两个调用分别进入 Circle::draw 与 Square::draw。
