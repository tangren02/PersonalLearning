## Q53：零拷贝的原理与实现技术

零拷贝使数据在处理和传输时不进行内存拷贝，直接在不同模块间传递，例如用户空间与内核空间之间；通过指针或引用传递，避免从一个缓冲区复制到另一个缓冲区。

**优点**：减少内存复制，提升传输性能；降低 CPU 负载；减少内存带宽和总线消耗，提高整体性能。
**场景**：高性能网络传输（如服务器传输大量数据）；文件 I/O（如复制、发送文件，减少用户空间与内核空间间拷贝）。
**实现技术**：

1. sendfile：Linux 中把文件数据从文件描述符直接发送到网络套接字。
2. mmap：将文件内容直接映射到进程地址空间。
3. splice：在两个文件描述符间移动数据，无需复制到用户空间。
4. DMA：设备直接访问主内存，减少 CPU 参与传输。

## Q54：strlen与sizeof的区别

| 比较项 | strlen | sizeof |
| --- | --- | --- |
| 含义 | 函数，计算 C 风格字符串长度，不包括结尾 null 字符 | 编译时运算符，计算对象、类型或结构的内存大小，单位为字节 |
| 参数 | 指向以 null 结尾字符数组的指针 | 变量、数组、指针、类型或表达式 |
| 返回类型 | size_t | size_t |
| 计算时机 | 运行时，扫描至第一个 null 字符 | 编译时确定，不依赖运行时状态 |

strlen 适合字符串实际长度和动态内容；sizeof 适合内存占用与数据布局大小。

### 示例片段

Hello 的字符串长度为 5，数组包含结尾 null 字符而占 6 字节；整数数组的总字节数取决于 int 大小，元素个数为 5。

```cpp
char str[] = "Hello";
strlen(str); // 5
sizeof(str); // 6
int arr[] = {1, 2, 3, 4, 5};
sizeof(arr); // 数组总字节数
sizeof(arr) / sizeof(arr[0]); // 5
```

## Q61：memcpy与strcpy的区别

memcpy 用于内存块拷贝，可拷贝任意类型数据；需要指定字节数，适合二进制数据。
strcpy 用于字符串拷贝，直到遇到 \0 结束符，适合字符串。
