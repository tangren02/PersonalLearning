## Q3：struct 与 union

| 比较项 | struct | union |
| --- | --- | --- |
| 存储空间 | 每个成员各有存储空间 | 所有成员共享同一块存储空间 |
| 大小 | 所有成员大小之和 | 最大成员的大小 |
| 使用与访问 | 可以同时存储、访问所有成员 | 一次只使用一种成员，只访问当前使用的成员 |
| 数据类型 | 同时保存多种数据类型 | 可以保存多种类型，但一次只用一种 |
| 使用场景 | 存储不同但相关的数据 | 节省内存，多个成员互斥使用 |

示例的两种类型都包含 int、float、char[20]。struct 同时保存各成员；union 依次给各成员赋值，并在赋值后输出对应成员。

## Q5：空类能实例化吗

能。空类实例仍需要最小的内存空间，通常为 1 字节，以确保不同对象具有不同的地址。示例创建 Empty e1、e2，输出对象大小及两个对象的地址。

## Q6：没有成员的类的 sizeof

class A 中没有任何成员变量和成员函数时，sizeof(A) 为 1。记忆理由：对象需要有独特的地址，因此即使为空也要占用空间。

## 示例片段：空类

摘取 Q6 的空类声明与待观察表达式，省略输出和 main；这里关注对象大小。

```cpp
class A {};
sizeof(A); // 值：1
```
