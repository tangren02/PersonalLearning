## Q1：C++ 三大特性

- 封装：将数据和方法封装在一起，隐藏内部实现，提供安全性和数据保护；通过 public、private、protected 控制访问。
- 继承：派生类继承基类的属性和方法，可以重写或扩展；表格列出 public、protected 继承。
- 多态：同一接口表现不同的行为，主要通过虚函数和覆盖实现。

示例中，Animal 将 name、age 设为 protected，定义虚函数 speak()、info() 和虚析构函数。Dog、Cat 覆盖虚函数；vector<Animal*> 保存 new 创建的 Dog、Cat，遍历调用 info()、speak()，最后 delete。

## Q2：struct 与 class

| 比较项 | struct | class |
| --- | --- | --- |
| 默认成员访问权限 | public | private |
| 默认继承权限 | public | private |
| 常见用途 | 简单数据结构 | 封装数据和行为 |
| 成员函数、继承、多态 | 支持 | 支持 |
| C 兼容性 | 与 C 兼容 | 与 C 不兼容 |

示例用 Person 的公开成员与 Person01 的私有 name、age 及 setName、setAge、display 方法作对比。

## Q7：子类不能继承父类的函数

构造函数、析构函数、拷贝构造函数、赋值运算符、私有成员函数。

Base、Derived 各自定义构造、析构、拷贝构造和赋值函数；Derived 的拷贝构造通过 Base(d) 调用基类操作，赋值显式调用 Base::operator=(d)；示例不调用父类的 privateFunction。

## 示例片段：示例中的基类拷贝与赋值调用

以下摘取 Q7 的两个调用位置，省略与记忆点无关的函数体和程序环境，不构成完整程序。

```cpp
Derived(const Derived& d) : Base(d) { /* 其余函数体省略 */ }
Derived& operator=(const Derived& d) {
    Base::operator=(d);
    // 其余函数体省略
    return *this;
}
```
