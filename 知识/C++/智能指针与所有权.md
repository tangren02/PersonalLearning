# 智能指针与所有权

AI 原创学习草稿，需用户核对；仅用于个人学习，不含工作资料。

## 面试要点

- `unique_ptr` 表示独占所有权，不可拷贝、可以移动。无共享需求时优先用它，借用对象可使用引用或不拥有资源的指针。
- `shared_ptr` 的副本共享控制块；最后一个强所有者释放时，所管理对象被销毁。不要用同一个裸指针分别构造两个独立的 `shared_ptr` 控制块。
- `weak_ptr` 不增加强引用计数，适合观察共享对象或打破强引用环；`lock()` 尝试获取可安全持有的 `shared_ptr`，失败时返回空指针。
- 控制块的并发支持不等于所指对象线程安全；并发修改对象数据仍需同步。

## 小例子与边界

```cpp
#include <memory>

struct Node {
    std::shared_ptr<Node> child;
    std::weak_ptr<Node> parent; // 反向观察，不形成双向强拥有
};

void example() {
    auto root = std::make_shared<Node>();
    root->child = std::make_shared<Node>();
    root->child->parent = root;
}
```

不同 `shared_ptr` 实例即使共享控制块，也可在不同线程中分别进行修改；同一个 `shared_ptr` 实例若被并发访问且存在非 const 操作，通常需要同步或原子接口。`use_count()` 的瞬时结果不能代替并发同步。

## 标准版本

C++11 提供这些智能指针与 `make_shared`。`make_unique` 从 C++14 开始。C++17 并未让 `shared_ptr<T>` 自动变成原子变量；C++11/14/17 可用针对 `shared_ptr` 的原子自由函数，`std::atomic<std::shared_ptr<T>>` 特化则从 C++20 开始，超出本轮重点。
