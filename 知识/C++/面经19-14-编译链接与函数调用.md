## Q44：extern "C" 的作用

1. **解除名称修饰**：C++ 为支持重载会修饰函数名；extern "C" 要求按 C 语言的简单名称处理。
2. **链接兼容性**：防止函数名称修改导致找不到符号，使 C++ 程序能够链接使用 C 编译器生成的代码。
3. **代码重用**：无需修改即可重用现有 C 库，提高效率与可重用性。
4. **接口标准化**：在 C/C++ 混合环境中提供声明接口的方式，使组件能衔接并便于管理。
5. **避免冲突**：防止 C++ 名称与 C 库全局符号冲突，适用于大型项目和多库环境。
6. **简化调用**：简化从 C++ 调用仅以 C 编写的函数库，如操作系统 API 和成熟 C 库。

## Q45：C++编译流程

1. **预处理**：处理宏定义、头文件包含、条件编译等指令。
2. **编译**：进行词法、语法和语义分析、中间代码生成与优化，把预处理后的代码转换成汇编代码。
3. **汇编**：把汇编代码转换成机器代码。
4. **链接**：将多个目标文件和库文件链接，生成可执行文件。

## Q46：编译器实现函数重载的方式

通过名称改编（Name Mangling）实现函数重载。
编译时把函数名称与参数类型组合成唯一符号，区分不同重载。

### 示例片段

同名 foo 的参数不同，对应的改编符号也不同；这里的符号是可能的形式。

```cpp
void foo(int) {}    // 可能变成 _Z3fooi
void foo(double) {} // 可能变成 _Z3food
```

## Q47：函数调用的压栈过程

1. **参数压栈**：从右到左将参数压入栈。
2. **返回地址压栈**：将函数返回地址压入栈。
3. **跳转**：跳转到函数代码。
4. **函数体执行**：执行函数中的具体代码。
5. **返回值处理**：将返回值存储在寄存器或栈中。
6. **栈清理和返回**：清理栈，返回调用位置。

### 示例片段

假设 foo(int a, double b) 已定义；调用中按上述过程处理两个参数、返回地址与返回。

```cpp
foo(42, 3.14);
```

## Q48：回调函数及使用场景

回调函数是一种委托机制：把函数指针作为参数传给另一个函数，由其在适当时机调用指针指向的函数。

1. **事件驱动编程**：处理 GUI 按钮点击、鼠标移动等事件。
2. **异步编程**：在网络异步 I/O 返回数据时处理结果。
3. **定时器**：到期调用函数，执行定时操作。
4. **函数式编程**：map、filter 等高阶函数接收回调，对集合元素操作。
5. **排序和搜索**：如 qsort 接收自定义比较函数，定制排序行为。

### 示例片段

假设 myCallbackFunction(int) 已定义；value>0 时调用传入的回调，示例传入 5。

```cpp
typedef void (*CallbackFunction)(int);
void performAction(int value, CallbackFunction callback) {
    if (value > 0) callback(value);
}
performAction(5, myCallbackFunction);
```
