## Q51：浅拷贝与深拷贝的区别

| 比较项 | 浅拷贝 | 深拷贝 |
| --- | --- | --- |
| 复制内容 | 只复制指针，不复制指向的内存 | 复制对象及其指针指向的所有内存内容 |
| 资源共享 | 多个对象共享同一内存资源 | 各对象拥有独立副本 |
| 修改副作用 | 一个对象修改会影响共享资源的其他对象 | 一个对象修改不影响其他对象 |

### 示例片段

摘取拷贝构造中的两种赋值方式；假设 data 与 source.data 都是 int*，且 source.data 指向有效整数，以下两行是不同分支，省略类体、析构和其余实现，只比较复制行为。

```cpp
data = source.data;           // 浅拷贝：共享指向的内存
data = new int(*source.data); // 深拷贝：新分配并复制内容
```

浅拷贝场景：obj1 的值为 100，obj2 由 obj1 浅拷贝得到；obj2 改成 300 后，obj1 也读到 300。深拷贝场景：obj3 的值为 200，obj4 由 obj3 深拷贝得到；obj4 改成 400 后，obj3 仍为 200。

## Q52：隐式转换与explicit

隐式转换是编译器自动把一种类型转换成另一种类型。
使用 explicit 关键字防止构造函数的隐式转换，确保只能显式调用构造函数。

## Q58：临时对象的产生与生命周期延长

1. **函数返回对象与返回值优化（RVO）**：通常生成临时对象，再通过优化直接转移给接收对象，避免不必要的拷贝和移动。
2. **隐式类型转换**：参数或返回值需要类型转换时，用临时对象存放转换后的值。
3. **运算符重载**：特别是运算结果返回时，会产生临时对象。
4. **按值传递或返回**：在拷贝或移动过程中产生临时对象。

**生命周期延长**：临时对象绑定到 const 引用时，其生命周期延长；列举的情形是局部作用域中的 const 引用，以及作为函数参数或返回值的 const 引用。

## Q59：返回值优化RVO与NRVO

**RVO（返回值优化）**：函数直接返回临时对象。
**NRVO（命名返回值优化）**：函数返回命名的局部对象。
返回值优化可以避免临时对象的创建和销毁。

### 示例片段

假设 MyClass 已定义；两个函数分别展示直接返回临时对象和返回具名局部对象。

```cpp
MyClass createObjectRVO() {
    return MyClass();
}
MyClass createObjectNRVO() {
    MyClass obj;
    return obj;
}
MyClass obj = createObjectRVO();
```

第一种可应用 RVO，第二种可应用 NRVO。
