## Q4：指针和引用的区别

| 比较项 | 指针 | 引用 |
| --- | --- | --- |
| 含义 | 存储地址 | 变量的别名 |
| 初始化与改变 | 可以改变指向 | 定义时初始化，不能重新绑定 |
| 空值 | 可以为 nullptr | 不可以为 nullptr |
| 多级形式 | 可以有多级指针 | 不可以有多级引用 |
| sizeof | 通常为 4 或 8 字节 | 原变量的大小 |
| 作为参数 | 传地址；改指针形参本身不影响实参指针，改所指值可影响原变量 | 直接操作实参 |
| 用途 | 动态内存、数组、指针运算 | 大对象或不可复制参数 |
| 安全性 | 灵活，但容易出现野指针、内存泄漏 | 限制较强，可避免某些错误，更安全 |

 ref 是 x 的别名。执行 ref=y 是赋值，不是重新绑定；y=20 时，x 变成 20。

## Q13：常量指针和指针常量

- 常量指针 const int*：不可通过它修改所指数据，可以改变指向。
- 指针常量 int* const：不可改变指向，可以修改所指数据。

示例中 ptr1 从指向 x 改为指向 y；ptr2 仍指向 x，并通过 *ptr2=30 修改 x。最后 x=30、y=20。

## Q18：引用作为函数参数的五个好处

1. 避免拷贝开销。
2. 支持修改实参。
3. 语法一致。
4. 传递大对象时效率更高。
5. 避免空指针问题，提高安全性。

示例通过 const vector<int>& 打印大小、int& 修改实参为 42、const int& 打印值，并创建大 vector 和 string 来展示参数传递。

## 示例片段：两种 const 指针

摘取 Q13 的赋值操作，省略输出与外围程序。注释中的两行是示例标出的不允许操作，保持注释，不作执行代码。

```cpp
int x = 10, y = 20;
const int* ptr1 = &x;
ptr1 = &y;
// *ptr1 = 25; // 错误：不能通过 ptr1 改数据
int* const ptr2 = &x;
*ptr2 = 30;
// ptr2 = &y;  // 错误：不能改变 ptr2 的指向
```
