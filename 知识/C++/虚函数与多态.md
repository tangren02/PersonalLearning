# 虚函数与多态

AI 原创学习草稿，需用户核对；仅用于个人学习，不含工作资料。

## 面试要点

- 通过基类指针或引用调用虚函数时，通常按对象的动态类型选择最终覆盖函数；显式限定调用 `obj.Base::f()` 会抑制虚派发。
- `override` 让编译器核对是否真正覆盖，避免参数、成员函数的 `const` 等不匹配而仅隐藏同名函数。
- 若允许通过基类指针 `delete` 派生对象，在 C++11/14/17 中基类析构函数需要是虚函数。不是所有基类都必须有虚析构；禁止经基类删除时，可设计为受保护的非虚析构。
- 将派生对象按值赋给基类对象会切片；基类对象不再含有派生部分，虚函数不能恢复被切掉的对象。

## 小例子与边界

```cpp
struct Base {
    virtual int value() const { return 1; }
    virtual ~Base() = default;
};
struct Derived : Base {
    int value() const override { return 2; }
};
int example() {
    Derived d;
    const Base& ref = d;
    return ref.value(); // 2
}
```

构造/析构期间调用虚函数，不会向尚未构造或已析构的更派生部分派发。纯虚析构函数仍然需要定义，因为派生对象析构时会执行基类析构。虚表是常见实现手段，不是标准强制的数据结构。

## 标准版本

运行时多态和虚析构早于 C++11；`override`、`final` 和 `= default` 从 C++11 开始。本文涉及的核心规则在 C++14、C++17 中不变；不要把较新标准的特殊删除规则套用到本轮版本。
