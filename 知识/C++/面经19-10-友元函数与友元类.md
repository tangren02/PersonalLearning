# 友元函数与友元类

## Q28：友元函数

友元函数是类外的函数，可以访问该类的私有成员和保护成员。在类定义中使用 friend 关键字声明。

### 示例片段

displayData 是类外函数，通过 friend 获得访问 data 的权限；假设 obj 已有效初始化，省略构造函数。

```cpp
class MyClass {
    int data;
    friend void displayData(const MyClass& obj);
};
void displayData(const MyClass& obj) {
    std::cout << obj.data;
}
```

## Q29：友元类

友元类可以访问另一个类的私有成员和保护成员。在类定义中使用 friend class 声明。

### 示例片段

B 是 A 的友元类，B 的成员函数可以读取 A 的私有 data；假设传入的 A 对象已有效初始化，省略构造和其余程序环境。

```cpp
class B;
class A {
    int data;
    friend class B;
};
class B {
public:
    void displayData(const A& obj) { std::cout << obj.data; }
};
```
