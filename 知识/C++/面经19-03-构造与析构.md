## Q7：父子类的函数

“子类不能继承的函数”为构造函数、析构函数、拷贝构造函数、赋值运算符、私有成员函数。Base、Derived 示例各自定义相应函数；Derived 拷贝构造调用 Base(d)，赋值时调用 Base::operator=(d)。

## Q8、Q11：初始化顺序

1. 先执行基类构造函数；有多个基类时，按继承列表顺序执行。
2. 再按成员在类中声明的顺序初始化成员，不按初始化列表书写顺序。
3. 最后执行构造函数主体。

Q8 示例的 Derived 继承 Base，成员依次为 member1、member2，输出先是 Base，再是两个 Member，最后是 Derived。Q11 先声明 a、后声明 b，即使列表写 b(y), a(x)，仍先初始化 a、再初始化 b；x=1、y=2 时输出 a=1、b=2。

## Q9：构造与析构顺序

构造：基类 → 成员声明顺序 → 派生类构造函数主体。

析构：派生类析构函数主体 → 成员声明逆序 → 基类析构函数。

示例的消息顺序：

- 构造：Base constructor → Member constructor → Member constructor → Derived constructor。
- 析构：Derived destructor → Member destructor → Member destructor → Base destructor。

## Q10：六类构造函数

| 名称 | 作用 |
| --- | --- |
| 默认构造函数 | 不带参数 |
| 参数化构造函数 | 接受参数，初始化对象 |
| 拷贝构造函数 | 用已有对象初始化新对象 |
| 移动构造函数 | 用临时对象初始化新对象 |
| 委托构造函数 | 一个构造函数调用另一个构造函数 |
| 显式构造函数 | 使用 explicit，防止隐式转换和复制初始化 |

## 示例片段：初始化列表

摘取 Q11 中的成员声明与初始化列表，省略输出和外围程序。预期：先 a 后 b；以 1、2 作为参数时，a=1、b=2。

```cpp
class Example {
    int a;
    int b;
public:
    Example(int x, int y) : b(y), a(x) { /* 输出省略 */ }
};
```

Q10 的记忆重点是上表的名称与作用。
