独占、共享、弱观察、临时借用对象，各优先考虑什么指针？
?
独占通常用 unique_ptr；真正共享拥有权用 shared_ptr；观察共享对象但不保活用 weak_ptr；临时借用用裸指针或引用并保证对象存活。补充与纠错：裸指针语法不自动证明“不拥有”，需看 API 契约；不要只因性能要求就默认改成手工 new/delete。
