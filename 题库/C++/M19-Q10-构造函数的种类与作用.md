C++ 有哪些构造函数？列出六类，并分别说明它们的作用。
?
1. **默认构造函数**：无参数的构造函数。
2. **参数化构造函数**：接受参数，用参数初始化对象。
3. **拷贝构造函数**：使用一个已有对象初始化新对象。
4. **移动构造函数**：使用临时对象初始化新对象。
5. **委托构造函数**：一个构造函数调用同类的另一个构造函数完成初始化。
6. **显式构造函数**：使用 `explicit`，防止隐式类型转换和复制初始化。
辅助片段：分别展示六类构造函数的形式，省略类体与其余实现；同参数签名的形式不放在同一个类中并列定义。
```cpp
MyClass();                           // 默认
MyClass(int val);                    // 参数化
MyClass(const MyClass& other);        // 拷贝
MyClass(MyClass&& other) noexcept;    // 移动
MyClass(int val1, int val2);          // 委托目标
MyClass(int val) : MyClass(val, 0) {} // 委托
explicit MyClass(int val);           // 显式
```
拷贝与移动的区别在于使用已有对象还是临时对象初始化新对象；委托是一个构造函数调用另一个构造函数，显式用于限制隐式转换和复制初始化。
