void f(int* p, int* q) { p=q; } 能改变调用方指针吗？若要修改所指 int 呢？
?
不能改变调用方指针，因为 p 是指针值的副本；改写 *p 可修改它所指向的有效 int。补充与纠错：如果目标是重设调用方指针，可用 int*& 或 int** 等明确接口；是否修改指针变量与是否修改所指对象是两个问题。
