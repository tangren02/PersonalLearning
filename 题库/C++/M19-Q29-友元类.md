什么是友元类？它可以访问另一个类的哪些成员，如何声明这种关系？
?
友元类可以访问另一个类的私有成员和保护成员。在类定义中使用 friend class 声明。
辅助片段：B 是 A 的友元类，B 的成员函数可以读取 A 的私有 data；假设传入的 A 对象已有效初始化，省略构造和其余程序环境。
```cpp
class B;
class A {
    int data;
    friend class B;
};
class B {
public:
    void displayData(const A& obj) { std::cout << obj.data; }
};
```
