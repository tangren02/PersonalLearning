C++ 函数调用的压栈与返回过程有哪些步骤？说明参数和返回地址如何入栈、函数如何执行、返回值如何处理以及如何返回调用位置。
?
1. **参数压栈**：从右到左将参数压入栈。
2. **返回地址压栈**：将函数返回地址压入栈。
3. **跳转**：跳转到函数代码。
4. **函数体执行**：执行函数中的具体代码。
5. **返回值处理**：将返回值存储在寄存器或栈中。
6. **栈清理和返回**：清理栈，返回调用位置。
辅助片段：假设 foo(int a, double b) 已定义；调用中按上述过程处理两个参数、返回地址与返回。
```cpp
foo(42, 3.14);
```
