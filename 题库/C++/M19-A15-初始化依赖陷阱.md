声明 int a; int b; 后写 T() : b(7), a(b) {}，为什么仍有问题？怎样修复？
?
a 按声明顺序先初始化，读取尚未初始化的 b；C++17 下读取这个未初始化 int 导致未定义行为。应调整声明使被依赖成员先初始化，或让 a 和 b 都从有效参数计算。补充与纠错：固定顺序不会自动修复依赖；原题的 b(y), a(x) 不存在同样的读取问题。
