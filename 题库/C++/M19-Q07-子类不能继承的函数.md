子类不能继承父类的哪些函数？列出各类函数，并说明派生类如何在自己的拷贝构造和赋值操作中调用基类的对应操作。
?
不能继承的函数包括：
1. 构造函数。
2. 析构函数。
3. 拷贝构造函数。
4. 赋值运算符。
5. 私有成员函数。
辅助片段：假定 `Base` 已定义对应的公有构造函数、析构函数和赋值运算符，省略各函数的输出。
```cpp
class Derived : public Base {
public:
    Derived() {}
    ~Derived() {}
    Derived(const Derived& d) : Base(d) {}
    Derived& operator=(const Derived& d) {
        Base::operator=(d);
        return *this;
    }
};
```
`Derived` 定义自己的对应函数；拷贝构造通过初始化列表中的 `Base(d)` 调用基类拷贝构造，赋值运算符通过 `Base::operator=(d)` 调用基类赋值操作。
