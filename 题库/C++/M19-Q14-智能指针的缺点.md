智能指针有哪些缺点？列出三项，并说明 shared_ptr 之间怎样形成循环引用，以及它可能造成的后果。
?
1. **性能开销**：智能指针会带来额外的管理开销。
2. **循环引用**：`shared_ptr` 之间相互持有，可能导致内存泄漏。
3. **代码复杂性增加**：所有权和生命周期的管理可能使代码更复杂。
循环引用辅助片段：
```cpp
struct Node {
    std::shared_ptr<Node> next;
};
auto node1 = std::make_shared<Node>();
auto node2 = std::make_shared<Node>();
node1->next = node2;
node2->next = node1;
```
两个节点通过各自的 `next` 相互持有对方的 `shared_ptr`，形成循环引用，导致内存泄漏。
使用时应避免循环引用，了解性能影响，并在必要时优化。
