C++ 中空类能否实例化？空类对象通常占多少内存，为什么？
?
空类可以实例化。即使没有成员变量和成员函数，仍可创建该类的对象。
空类对象通常占 1 字节，以使不同对象具有不同的地址。
辅助片段：
```cpp
class Empty {};
Empty e1, e2; // 可以创建两个实例
// sizeof(Empty) 为 1，e1 和 e2 的地址不同
```
