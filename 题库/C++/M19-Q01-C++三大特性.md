C++ 的三大特性是什么？分别说明它们的含义、作用和实现方式。
?
1. **封装**：把数据和方法封装在一起，隐藏内部实现，提供安全性和数据保护。通过 `public`、`private`、`protected` 访问控制实现，例如将数据设为私有，通过公有方法访问。
2. **继承**：派生类继承基类的属性和方法，并可重写或扩展，实现代码复用。继承方式包括 `public` 继承、`protected` 继承；例如汽车和自行车继承车辆的属性与方法。
3. **多态**：通过同一接口表现不同的行为，实现接口复用和行为修改，主要通过虚函数和覆盖实现；例如不同图形通过相同绘图接口呈现各自行为。
辅助片段：只保留数据访问控制、`Dog` 的继承和虚函数调用。
```cpp
class Animal {
protected:
    std::string name;
    int age;
public:
    Animal(std::string n, int a) : name(n), age(a) {}
    virtual void speak() const { std::cout << "Some animal sound\n"; }
    virtual ~Animal() {}
};
class Dog : public Animal {
public:
    Dog(std::string n, int a) : Animal(n, a) {}
    void speak() const override { std::cout << "Woof!\n"; }
};
Animal* animal = new Dog("Buddy", 5);
animal->speak(); // 经基类指针调用 Dog::speak()，输出 Woof!
delete animal;
```
`name`、`age` 通过 `protected` 隐藏；`Dog` 继承 `Animal`；经基类指针调用虚函数时，执行派生类覆盖的行为。
