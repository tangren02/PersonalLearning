阅读下面的辅助片段：show 是虚函数，print 是非虚函数；各 print 的输出实现省略。
```cpp
class Base {
public:
    virtual void show() { print(); }
    void print() { /* 输出 Base print */ }
};
class Derived : public Base {
public:
    void show() override { print(); }
    void print() { /* 输出 Derived print */ }
};
Derived d;
Base* b = &d;
b->show();
```
执行 b->show() 时：
1. 进入 Base::show() 还是 Derived::show()？这是动态绑定还是静态绑定？
2. 随后，show() 内的 print() 调用 Base::print() 还是 Derived::print()？这是动态绑定还是静态绑定？
?
1. 进入 Derived::show()：虚函数通过虚函数表进行动态绑定，调用实际对象 d 的虚函数实现。
2. 调用 Derived::print()：print 是非虚函数，采用静态绑定，在编译时确定调用哪个函数；此处调用位于 Derived::show() 中。
完整调用路径：b->show() → Derived::show() → Derived::print()。
