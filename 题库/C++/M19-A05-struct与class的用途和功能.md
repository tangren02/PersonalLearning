除默认权限外，如何比较 struct 与 class 的用途、功能和 C 兼容性？
?
用途：struct 常用于简单数据结构；class 常用于封装数据和行为。
功能：两者都支持成员函数、继承和多态。
C 兼容性：struct 与 C 兼容，class 与 C 不兼容。
