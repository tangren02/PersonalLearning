sizeof(Empty) > 0，为什么 struct D : Empty { int x; }; 仍可能与 int 一样大？
?
补充与纠错：sizeof(Empty) 描述完整 Empty 对象的大小；作为基类子对象时，空基类优化可能使它不额外占空间。二者不是同一布局条件，因此不矛盾。具体 sizeof(D) 仍需按标准约束和实现判断，不保证所有继承布局都消除空基类开销。
