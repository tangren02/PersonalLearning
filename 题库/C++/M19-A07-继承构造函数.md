C++17 能继承基类构造函数吗？给出最短写法并说一个边界。
?
补充与纠错：可以，例如 struct D : B { using B::B; int x = 9; };。D d(7) 可使用适用的 B 构造函数初始化基类部分，其余成员仍按规则初始化。它不会把 B(const B&) 变成 D(const D&)；派生类拷贝、移动仍按自己的特殊成员规则处理。
