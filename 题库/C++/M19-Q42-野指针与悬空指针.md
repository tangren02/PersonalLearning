什么是野指针和悬空指针？分别说明常见成因、使用风险，以及释放内存后的指针处理方式。
?
**野指针**指向随机或不确定的内存地址，通常由未初始化指针造成；指向的内存被释放或重新使用后未及时清零、重新赋值也可能形成这种风险。操作它可能读写不属于程序的区域，导致数据损坏或崩溃。
**悬空指针**指向已经释放的内存；删除对象或内存后未及时把指针设为 nullptr，继续访问可能产生未定义行为、数据损坏或程序异常。
释放内存后将指针设为 nullptr。
辅助片段：错误访问保留为注释，不应执行；展示未初始化与释放后的两个边界。
```cpp
int* wildPtr;
// *wildPtr; // 未定义行为：未初始化
int* danglingPtr = new int(10);
delete danglingPtr;
// *danglingPtr; // 未定义行为：内存已释放
danglingPtr = nullptr;
```
