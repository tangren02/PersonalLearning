函数返回 T 时，return T{} 与 return local（local 是非 volatile 的自动局部 T 对象且不是参数）在 C++17 中是否都强制消除拷贝？
?
- return T{} 的同类型纯右值在 C++17 直接构造结果对象，不需要拷贝或移动构造，但仍有析构可访问等要求。
- return local 是 NRVO 场景，C++17 仍允许而非强制执行；未消除时需遵循相应构造规则。
- 在 C++11/14，相应纯右值场景的消除属于允许优化，而非 C++17 的强制语义。
- 不要为“加速”把 return local 改成 return std::move(local)，这样会妨碍 NRVO。
