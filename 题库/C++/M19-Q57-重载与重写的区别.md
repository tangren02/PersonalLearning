重载与重写在定义层次、参数列表、关键字和目的上有什么区别？
?
| 比较项 | 重载 | 重写 |
| --- | --- | --- |
| 定义层次 | 同一作用域 | 派生类与基类 |
| 参数列表 | 不同 | 相同 |
| 关键字 | 不需要特殊关键字 | 基类函数使用 virtual |
| 目的 | 同名函数提供不同实现 | 派生类提供基类函数的不同实现 |
辅助片段：省略输出实现；Derived 的无参 display 重写基类虚函数，同类内的 display(int) 提供另一个参数列表。
```cpp
class Base {
public:
    virtual void display() const {}
};
class Derived : public Base {
public:
    void display() const override {}
    void display(int x) const {}
};
Derived derived;
derived.display();
derived.display(10);
```
