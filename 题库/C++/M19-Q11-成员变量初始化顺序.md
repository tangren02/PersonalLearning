C++ 成员变量的初始化顺序由什么决定？当类内声明顺序与构造函数初始化列表的书写顺序不一致时，以哪个为准？
?
成员变量严格按它们在类中的声明顺序初始化，不按构造函数初始化列表的书写顺序初始化。
辅助片段：
```cpp
class Example {
    int a; // 先声明
    int b; // 后声明
public:
    Example(int x, int y) : b(y), a(x) {}
};
Example obj(1, 2);
```
虽然初始化列表先写 `b(y)`，实际仍先初始化 `a`、再初始化 `b`。用 `(1, 2)` 构造后，两个成员的值为 `a = 1`、`b = 2`；在成员函数中输出时结果为 `a: 1, b: 2`。
