为什么“局部变量都在栈上且没有初值”不准确？给出两个反例。
?
补充与纠错：局部 static int n; 具有静态存储期并零初始化；普通局部 int x{}; 值初始化为零。类类型还可能由构造函数初始化。栈/数据段是常见实现方式，不是所有 C++ 对象的强制位置；只有类似普通自动 int x; 的未初始化情形不能直接读取该 int。
