虚继承解决什么问题？多继承中重复的继承路径会产生什么后果，虚继承如何处理？
?
虚继承用于解决菱形继承（钻石继承）。
多继承中的重复继承路径会使基类成员重复继承，产生冗余和潜在二义性。通过虚基类，基类成员在继承链中只存在一份。
辅助片段：Derived1、Derived2 都虚继承 Base，Final 通过两条路径继承后仍可直接访问一份 value。
```cpp
class Base { public: int value; };
class Derived1 : virtual public Base {};
class Derived2 : virtual public Base {};
class Final : public Derived1, public Derived2 {};
Final f;
f.value = 10;
```
