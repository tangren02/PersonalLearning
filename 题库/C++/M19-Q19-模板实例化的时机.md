C++ 模板在什么时候实例化？说明具体使用与实例化的关系、开发者能否显式指定实例化，以及链接阶段对实例化定义的要求。
?
1. **编译期实例化**：编译器遇到模板的具体使用，例如调用函数模板或创建类模板实例时，为相应类型实例化并生成代码。
2. **显式实例化**：开发者也可以显式指定需要实例化的模板。
3. **链接阶段**：需要确保各实例化的定义可见。
辅助片段：只保留模板定义与两种具体类型的使用。
```cpp
template <typename T>
class MyClass {
public:
    T data;
    MyClass(T d) : data(d) {}
};
MyClass<int> obj1(42);
MyClass<double> obj2(3.14);
```
这两处具体使用分别涉及 `MyClass<int>` 和 `MyClass<double>` 的实例化。
