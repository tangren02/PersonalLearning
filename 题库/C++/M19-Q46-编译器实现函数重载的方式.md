编译器在底层如何区分同名的重载函数？说明名称改编如何生成不同符号。
?
通过名称改编（Name Mangling）实现函数重载。
编译时把函数名称与参数类型组合成唯一符号，区分不同重载。
辅助片段：同名 foo 的参数不同，对应的改编符号也不同；这里的符号是可能的形式。
```cpp
void foo(int) {}    // 可能变成 _Z3fooi
void foo(double) {} // 可能变成 _Z3food
```
