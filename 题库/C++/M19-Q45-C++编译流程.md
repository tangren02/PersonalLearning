C++ 从源代码到可执行文件经历哪四个阶段？各阶段分别处理什么并生成什么？
?
1. **预处理**：处理宏定义、头文件包含、条件编译等指令。
2. **编译**：进行词法、语法和语义分析、中间代码生成与优化，把预处理后的代码转换成汇编代码。
3. **汇编**：把汇编代码转换成机器代码。
4. **链接**：将多个目标文件和库文件链接，生成可执行文件。
