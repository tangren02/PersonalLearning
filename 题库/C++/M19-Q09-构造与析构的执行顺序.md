C++ 中派生类对象的构造与析构分别按什么顺序执行？说明基类、成员对象和派生类函数体的先后关系，以及多个成员的处理顺序。
?
构造顺序：基类构造函数 → 成员对象按类内声明顺序构造 → 派生类构造函数体。
析构顺序：派生类析构函数体 → 成员对象按类内声明的逆序析构 → 基类析构函数。
辅助片段：假定 `Base`、`Member` 的构造和析构函数分别输出自身类型及 `constructor`、`destructor`，省略它们的定义。
```cpp
class Derived : public Base {
public:
    Member m1;
    Member m2;
    Derived() { std::cout << "Derived constructor\n"; }
    ~Derived() { std::cout << "Derived destructor\n"; }
};
{ Derived d; } // 离开作用域时销毁 d
```
创建并销毁 `d` 时，输出顺序如下：
```text
Base constructor
Member constructor
Member constructor
Derived constructor
Derived destructor
Member destructor
Member destructor
Base destructor
```
其中两个成员的构造顺序为 `m1 → m2`，析构顺序为 `m2 → m1`。
