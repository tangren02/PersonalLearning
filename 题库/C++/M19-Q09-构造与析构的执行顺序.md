C++ 中派生类对象的构造与析构分别按什么顺序执行？说明基类、成员对象和派生类函数体的先后关系，以及多个成员的处理顺序。
?
构造顺序：基类构造函数 → 成员对象按类内声明顺序构造 → 派生类构造函数体。
析构顺序：派生类析构函数体 → 成员对象按类内声明的逆序析构 → 基类析构函数。
辅助示例：`Derived` 继承 `Base`，依次声明 `Member member1`、`Member member2`；各构造、析构函数输出自身名称。创建并销毁一个 `Derived` 对象时，输出顺序如下：
```text
Base constructor
Member constructor
Member constructor
Derived constructor
Derived destructor
Member destructor
Member destructor
Base destructor
```
其中两个成员的构造顺序为 `member1 → member2`，析构顺序为 `member2 → member1`。
