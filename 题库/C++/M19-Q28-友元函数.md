什么是友元函数？它可以访问类的哪些成员，如何在类中声明？
?
友元函数是类外的函数，可以访问该类的私有成员和保护成员。在类定义中使用 friend 关键字声明。
辅助片段：displayData 是类外函数，通过 friend 获得访问 data 的权限；假设 obj 已有效初始化，省略构造函数。
```cpp
class MyClass {
    int data;
    friend void displayData(const MyClass& obj);
};
void displayData(const MyClass& obj) {
    std::cout << obj.data;
}
```
