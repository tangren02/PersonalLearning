需要用 new 分配内存，但事先不确定大小时，可以采取哪三种处理方式？
?
1. **确定最大可能大小**：预先确定最大可能大小，再用 new 分配。
2. **动态调整大小**：使用 std::vector 或 std::unique_ptr 等，根据需要动态调整内存大小。
3. **类型擦除与多态**：使用基类指针指向派生类对象，动态确定对象的实际类型和大小。
辅助片段：假设 numElements 是运行时取得的正整数，按该数量分配、使用并释放数组。
```cpp
int* array = new int[numElements];
for (int i = 0; i < numElements; ++i) {
    array[i] = i;
}
delete[] array;
```
