如果模板只支持 int 等有限类型，能把实现放 cpp 吗？extern template 是实现吗？
?
补充与纠错：可以在实现文件放定义，并提供所支持类型的显式实例化定义，例如 template int twice<int>(int);，让使用方链接该实体。extern template 是显式实例化声明，可抑制相应隐式实例化，但仍需别处提供定义；没有提供的类型不会自动可用。
