什么是内存对齐？它在访问速度、硬件错误、硬件与编译器约定、平台兼容性和缓存利用率方面有哪些作用？
?
内存对齐是安排数据存储和访问的技术，用于提高内存访问效率。
1. **提高访问速度**：把数据放在处理器预期的地址上，以单个或较少内存访问周期完成读写，减少访问次数。
2. **防止硬件错误**：某些处理器（如 ARM、SPARC）访问未对齐数据可能触发硬件异常。
3. **遵守硬件和编译器约定**：满足 CPU 架构与编译器的对齐要求，优化执行和性能。
4. **平台兼容性**：保证不同平台间数据结构的一致性和正确解析，尤其在网络通信、文件格式中。
5. **提高缓存利用率**：更可能与缓存行边界对齐，减少缓存行加载次数和缓存未命中。
辅助片段：假设 int 为 4 字节。Aligned 展示自然对齐；Unaligned 用 pack(1) 强制紧凑布局，可能造成性能下降或硬件错误，不作安全访问示例。
```cpp
struct Aligned { int a; int b; int c; };
#pragma pack(push, 1)
struct Unaligned {
    char x; int a;
    char y; int b;
    char z; int c;
};
#pragma pack(pop)
```
