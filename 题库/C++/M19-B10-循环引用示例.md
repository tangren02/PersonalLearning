两个 Node 如何形成循环引用？这种情况有什么问题？
?
两个 Node 各有 shared_ptr 类型的 next：node1->next 指向 node2，node2->next 指向 node1。
双方相互持有 shared_ptr，形成循环引用，可能导致内存泄漏。
