C++ 中用引用作为函数参数有哪些好处？列出五项，并说明只读引用参数和可修改引用参数分别如何使用。
?
1. 避免拷贝开销。
2. 可以直接修改实参。
3. 语法与直接使用对象保持一致。
4. 传递大对象时效率较高。
5. 避免空指针，使用更安全。
只读参数可使用 const 引用；需要修改实参时可使用非 const 引用。
辅助片段：
```cpp
void processLargeData(const std::vector<int>& data); // 只读传递大容器
void modifyValue(int& value) { value = 42; }         // 修改调用方实参
void printValue(const int& value);                  // 只读访问值
```
