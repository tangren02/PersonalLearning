C++ 中用引用作为函数参数有哪些好处？列出五项，并说明只读引用参数和可修改引用参数分别如何使用。
?
1. 避免拷贝开销。
2. 可以直接修改实参。
3. 语法与直接使用对象保持一致。
4. 传递大对象时效率较高。
5. 避免空指针，使用更安全。
只读参数可使用 const 引用；需要修改实参时可使用非 const 引用。
辅助片段：
```cpp
void processLargeVector(const std::vector<int>& vec) { std::cout << vec.size(); }
void updateValue(int& x) { x = 42; }
void printValue(const int& x) { std::cout << x; }
int a = 10;
updateValue(a); // 修改实参，a 变为 42
printValue(a);  // 通过 const 引用读取，输出 42
std::vector<int> largeVector(1000000, 1);
processLargeVector(largeVector); // 引用传递大容器，避免拷贝
```
