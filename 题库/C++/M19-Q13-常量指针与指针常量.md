常量指针 `const int*` 与指针常量 `int* const` 有什么区别？分别说明能否改变指向，以及能否通过指针修改所指数据。
?
常量指针 `const int*`：不能通过该指针修改所指数据，但可以改变指针指向。
指针常量 `int* const`：不能改变指针指向，但可以通过该指针修改所指数据。
辅助片段：
```cpp
int x = 10, y = 20;
const int* ptr1 = &x;
ptr1 = &y;           // 允许：改变指向
// *ptr1 = 30;       // 错误：不能通过 ptr1 修改所指数据
int* const ptr2 = &x;
*ptr2 = 30;          // 允许：修改 x
// ptr2 = &y;        // 错误：不能改变 ptr2 的指向
```
执行允许的操作后，`ptr1` 指向 `y`，`ptr2` 仍指向 `x`，最终 `x = 30`、`y = 20`。注释中的两条错误操作不执行。
