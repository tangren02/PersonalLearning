C++ 构造函数初始化列表涉及的基类和成员按什么顺序初始化，构造函数体何时执行？多个基类和多个成员各按什么顺序处理，成员顺序是否取决于初始化列表的书写顺序？
?
1. 先构造基类；有多个基类时，按它们在继承列表中的顺序构造。
2. 再初始化成员变量，严格按成员在类中的声明顺序，而不是初始化列表的书写顺序。
3. 最后执行派生类构造函数体。
成员按声明顺序初始化，是为了处理成员间的依赖，避免使用尚未初始化的成员。
辅助片段：假定 `Base`、`Member` 已定义构造函数，省略输出语句。
```cpp
class Derived : public Base {
    Member member1;
    Member member2;
public:
    Derived() : member1(), member2() {}
};
Derived d;
```
创建 `d` 时，先构造 `Base`，再按声明顺序构造 `member1`、`member2`，最后执行 `Derived` 构造函数体。
