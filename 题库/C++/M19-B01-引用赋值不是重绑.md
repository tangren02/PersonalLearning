int x=1, y=2; int& r=x; r=y; 后 x 是多少，r 绑定谁？sizeof(r) 表示什么？
?
x 变为 2，r 仍绑定 x；赋值修改被引用对象，不是重新绑定。sizeof(r) 是被引用类型 int 的大小，&r 得到 x 的地址。指针则是独立对象，可以改指向或保存 nullptr；sizeof 指针是指针类型的大小。
