C++ 中指针和引用有什么区别？比较它们的含义、初始化与绑定、层级、空值、sizeof、形参传递及适用场景，并说明“给引用赋值”与“改变指针指向”的区别。
?
| 比较项 | 指针 | 引用 |
| --- | --- | --- |
| 含义 | 存储内存地址的变量 | 已有变量的别名 |
| 初始化与绑定 | 可取 nullptr 或其他指针值，之后可改变指向 | 定义时必须绑定变量，之后不能重新绑定 |
| 层级 | 可以有多级指针 | 没有多级引用，因为它们不具有独立的内存地址 |
| 空值 | 可以为空 | 不能为空 |
| sizeof | 指针本身的大小，通常为 4 或 8 字节 | 所绑定变量的大小 |
| 作为形参 | 传递地址，修改形参指针本身不影响实参指针，但修改所指向的值会影响原变量 | 直接操作实参 |
| 适用场景 | 动态内存管理、数组操作、指针算术等 | 大对象或不可复制对象的参数传递、多级间接引用等场景 |
| 特点 | 灵活，但容易出现野指针和内存泄漏 | 限制较强，使用较安全 |
改变指针指向会使指针访问另一个变量；给引用赋值会修改它原来绑定的变量，不会改变绑定关系。
辅助片段：
```cpp
int x = 10, y = 20;
int* ptr = &x; // *ptr 为 10
ptr = &y;      // *ptr 为 20，改为指向 y
int& ref = x;
ref = y;       // 把 20 赋给 x，ref 仍绑定 x
```
