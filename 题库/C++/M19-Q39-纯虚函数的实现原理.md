纯虚函数如何定义接口？含纯虚函数的类能否实例化？它如何通过 vtable、vptr 和动态绑定调用派生类实现？
?
纯虚函数用于定义接口，没有具体实现；含纯虚函数的类是抽象类，不能实例化。
它依赖 vtable 和 vptr：编译器为包含虚函数的类生成虚函数表，表中保存虚函数指针；对象包含指向该表的 vptr，运行时通过二者实现动态绑定。
辅助片段：Base 用 =0 定义纯虚函数，Derived 实现 show；通过 Base 指针调用的是 Derived 的实现。
```cpp
class Base {
public:
    virtual void show() = 0;
};
class Derived : public Base {
public:
    void show() override { /* 输出派生类实现 */ }
};
Derived d;
Base* b = &d;
b->show();
```
