# Cursor 快捷键

面向 macOS：文件查找、代码阅读、日常编辑、终端与 Cursor AI 操作。按“想做什么”查找，不要求一次记住全部。

## 快捷键记法

`⌘` = Command，`⌥` = Option，`⌃` = Control，`⇧` = Shift。功能键可能需要配合 `Fn`。快捷键以 Cursor 3.22.12 的命令注册为参考，未逐项实测；焦点所在区域、输入法、扩展和自定义键位会影响结果。

先记这几个：`⌘P` 找文件、`⇧⌘P` 找命令、`⇧⌘F` 全局搜索、`⌃−` 返回、`⌘/` 注释、`⌃ + 反引号` 终端、`⌘I` Chat、`⌘K` 行内 AI 编辑。

### 查找、阅读与导航

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 按文件名快速打开 | `⌘P` | 输入文件名筛选 |
| 打开命令面板 | `⇧⌘P` 或 `F1` | 忘记快捷键时，搜索命令名 |
| 在整个工作区搜索文本 | `⇧⌘F` | 先注意搜索范围和排除规则 |
| 跳到某行/列 | `⌃G` | 例如输入 `42` 跳到第 42 行 |
| 回到上一个位置 | `⌃−` | 有导航历史时可用，适合跳转后返回 |
| 返回前进位置 | `⇧⌃−` | 在后退之后前进 |
| 跳到下一个/上一个问题 | `F8` / `⇧F8` | 编辑器聚焦；需要已有诊断信息，不代表运行测试 |

### 编辑与格式化

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 切换行注释 | `⌘/` | 光标在可编辑文本中；选中多行可一起操作 |
| 选中下一个相同文本 | `⌘D` | 重复按可逐个添加匹配，适合局部批量编辑 |
| 格式化整个文档 | `⇧⌥F` | 需要该语言的格式化器；可能改动整篇，先看差异 |

常规文本操作：`⌘S` 保存、`⌘F` 文件内查找、`⌘Z` 撤销、`⇧⌘Z` 重做。更多通用操作可参考 [[工具快捷键/VS Code|VS Code 快捷键]]，但涉及 `⌘K` 前缀、`⌘L` 和 AI 冲突时，以 Cursor 的实际绑定为准。

### 终端

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 显示/隐藏集成终端 | `⌃` + 反引号 | 是 Control，不是 Command |
| 新建终端 | `⇧⌃` + 反引号 | 新开一个终端会话，不是切换现有会话 |
| 在终端打开 AI 生成 | `⌘K` | 终端聚焦时；不要把它记成固定的“清屏” |
| 关闭终端 AI 提示栏 | `Esc` | 提示栏显示时 |

### Cursor AI

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 打开 Chat | `⌘I` | 本版注册命令为 `composer.startComposerPrompt` |
| 打开 Chat（另一入口） | `⌘L` | 受布局/焦点影响；行内提示栏聚焦时可能是发送到 Agent，浏览器中可能定位地址栏 |
| 新建 Agent Chat | `⇧⌘I` | 本版也注册了 `⇧⌘L`，但后者存在多选命令冲突 |
| 打开行内 AI 编辑 | `⌘K` | 编辑器聚焦时；已有提示栏或其他上下文时行为可能不同 |

打开 AI 面板不等于已经发送请求。

## 两个不能直接照搬 VS Code 的键位

- **`⌘K`**：Cursor 用它做行内 AI 编辑、提示栏焦点切换和终端 AI。传统 `⌘K` 两步组合键不能假定全部原样适用。
- **`⇧⌘L`**：此版本同时注册“全选匹配”和“新建 Agent Chat”，后者注册优先级更高。这里不把它列为可靠的全选匹配快捷键；可用命令面板搜索 `Select All Occurrences of Find Match`，或在快捷键页为该命令选择不冲突的键。具体触发结果以当前上下文为准。

## 自己查询实际键位

1. 打开 **Cursor → Preferences → Keyboard Shortcuts**。此版本菜单快捷键为先按 `⌘R`、再按 `⌘S`，不要直接套用 VS Code 的 `⌘K`、`⌘S`。
2. 搜索操作名或命令 ID，例如 `editor.action.formatDocument`（格式化）、`editor.action.selectHighlights`（全选匹配）、`composer.newAgentChat`（新 Agent Chat）。
3. 查看同一个按键绑定的其他命令及 `When` 条件；只在编辑器、终端或输入框中的某个区域生效，是正常的上下文设计。

升级 Cursor、导入其他编辑器配置、安装键位扩展或切换布局后，应重新核对，尤其是 AI 快捷键。
