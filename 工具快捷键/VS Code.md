# VS Code 快捷键

面向 macOS：读代码、Review 改动和日常编码。按“想做什么”查找，不要求一次记住全部。

`⌘` = Command，`⌥` = Option，`⌃` = Control，`⇧` = Shift。同行中的“／”表示两项操作分别对应两个快捷键。功能键若被系统用于亮度、音量等控制，可能需要同时按 `Fn`。

## 文件与标签页

| 想做什么        | 快捷键             | 条件或提醒                                   |
| ----------- | --------------- | --------------------------------------- |
| 新建文件        | `⌘N`            | 新建未命名文本，保存时再选择路径                        |
| 保存全部文件      | `⌘⌥S`           | 保存有未保存更改的编辑器                            |
| 关闭当前文件标签页   | `⌘W`            | 关闭当前编辑器，不是删除磁盘文件；留意未保存内容的处理提示           |
| 重新打开刚关闭的标签页 | `⌘⇧T`           | 重新打开关闭的编辑器，不是恢复已删除的文件                   |
| 关闭全部编辑器     | 先按 `⌘K`，再按 `⌘W` | 两步组合键，不是四键同时按；固定（sticky）的编辑器会保留，留意未保存内容 |

## 阅读与导航

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 按文件名快速打开文件 | `⌘P` | 输入文件名查找 |
| 打开命令面板 | `⌘⇧P` 或 `F1` | 忘记快捷键时，先搜索命令名称 |
| 跳到当前文件中的函数、类等符号 | `⌘⇧O` | 符号内容依赖语言支持 |
| 查找整个工作区的符号 | `⌘T` | 适合知道函数或类名、不知道文件位置时 |
| 跳转到定义 | `F12` | 光标放在符号上；需要语言扩展提供定义信息 |
| 查找引用 | `⇧F12` | 编辑器聚焦；需要语言支持 |
| 回到上一个位置／返回前进位置 | `⌃-` ／ `⌃⇧-` | 有导航历史时可用，适合跳转定义后回来 |

## Review 改动

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 跳到下一处／上一处差异 | `⌥F5` ／ `⌥⇧F5` | 在差异编辑器中使用，不是切换下一个文件 |
| 查看问题面板 | `⌘⇧M` | 查看语言扩展等报告的错误和警告；不代表代码已运行验证 |

常用路径：按 `⌃⇧G` 打开“源代码管理”，打开一个变更文件的差异视图 → 用差异跳转逐块查看 → 需要理解上下文时跳转定义或查找引用 → 用 `⌃-` 回来。

## 搜索与替换

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 在当前文件查找 | `⌘F` | 适合查变量名或文本 |
| 在当前文件替换 | `⌘⌥F` | 替换前确认匹配范围 |
| 在工作区搜索 | `⌘⇧F` | 也是默认的搜索侧栏入口；找调用位置、配置项或报错文本 |
| 在工作区搜索并替换 | `⌘⇧H` | 批量修改前检查命中文件与替换内容 |

## 日常编辑

以下操作通常需要焦点在代码编辑器中；修改操作要求文件可写。

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 切换行注释 | `⌘/` | 可用于当前行或选中的多行 |
| 切换块注释 | `⇧⌥A` | 注释形式取决于语言 |
| 向上／向下移动行 | `⌥↑` ／ `⌥↓` | 调整代码位置 |
| 向上／向下复制行 | `⇧⌥↑` ／ `⇧⌥↓` | 不必先复制再粘贴 |
| 删除行 | `⌘⇧K` | 删除当前行或所选行 |
| 在上方／下方增加光标 | `⌘⌥↑` ／ `⌘⌥↓` | 对相邻多行同时编辑 |
| 选择下一处匹配 | `⌘D` | 连续使用可逐个增加匹配选区，进行多处编辑 |
| 重命名符号 | `F2` | 需要语言扩展支持；比单纯文本替换更适合符号改名 |
| 格式化文档 | `⇧⌥F` | 需要适用的格式化工具；缺少工具时可能显示配置提示 |
| 打开快速修复 | `⌘.` | 需要当前位置有语言扩展提供的代码操作 |
| 触发编辑器建议 | `⌃Space` | 普通语言补全，需要补全提供器 |

## 左侧栏入口

| 想做什么                | 快捷键   | 条件或提醒                                            |
| ------------------- | ----- | ------------------------------------------------ |
| 打开资源管理器（项目文件／源代码目录） | `⌘⇧E` | 打开并聚焦资源管理器，浏览项目文件                                |
| 打开源代码管理（Git）        | `⌃⇧G` | 注意是 Control，不是 Command；查看 Git 变更需要项目是 Git 仓库     |
| 打开搜索／在工作区搜索         | `⌘⇧F` | 默认打开并聚焦搜索侧栏；若将 `search.mode` 改为搜索编辑器模式，则会进入搜索编辑器 |

## 窗口与终端

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 分屏编辑器 | `⌘\` | 方便同时阅读两个文件 |
| 切换到下一／上一编辑器 | `⌘⌥→` ／ `⌘⌥←` | 也可用 `⌘⇧]` ／ `⌘⇧[` |
| 显示／隐藏侧栏 | `⌘B` | 留出更多代码阅读空间 |
| 显示／隐藏集成终端 | Control + 反引号（\`） | 按的是 Control（⌃），不是 Command（⌘）；只切换终端界面，不会自动连接或启动 Docker 容器 |

反引号通常位于键盘左上角、数字 `1` 左边，不是单引号（`'`）。同时按住 Control 和反引号键即可显示或隐藏集成终端。

## 本机自定义：添加到 Codex 会话

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 添加到 Codex 会话 | `⌃⌘I`（Control + Command + I） | `chatgpt.addToThread`；需要 Codex 扩展启用，且焦点在本地文件编辑器中（`editorTextFocus && resourceScheme == file`） |

本机配置移除了原“打开聊天”（`workbench.action.chat.open`）的这组快捷键，改绑为 `chatgpt.addToThread`。它不是单纯的“打开 Codex 侧栏”命令；要打开侧栏，可在命令面板搜索 `Open Codex Sidebar`（`chatgpt.openSidebar`）。

配置保存在本机用户 `keybindings.json` 中。若要撤销这组自定义，在该文件中删除 `-workbench.action.chat.open` 和 `chatgpt.addToThread` 两条 `ctrl+cmd+i` 规则即可；不要删除其他键位规则。

## 本机自定义：Code Runner

这两项来自本机用户键位文件，不是 VS Code 默认的项目运行或调试快捷键。

| 想做什么 | 快捷键 | 条件或提醒 |
| --- | --- | --- |
| 执行 Code Runner 的运行命令 | `⌘R` | `code-runner.run`；要求该扩展启用 |
| 执行 Code Runner 的停止命令 | `⌘⇧R` | `code-runner.stop`；不是通用的 Docker 停止命令 |

配置同时移除了 Code Runner 原有的 `⌃⌥N` 和 `⌃⌥M`。实际运行环境由扩展及项目配置决定，不能把 `⌘R` 理解成“在 Docker 中运行项目”。

## 查不到或按了没反应

用命令面板搜索“键盘快捷方式”，进入快捷键列表，按操作名称检查绑定及 `when` 条件。先确认焦点在编辑器、差异视图还是终端；再检查当前配置文件（Profile）、扩展和系统是否影响按键。
